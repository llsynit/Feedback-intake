# Feedback-intake
 
Dette er Statpeds mottak for tilbakemeldinger og diskusjoner om våre digitale ressurser og prosjekter.
 
> [!Warning]
> Dette repoet er offentlig. Alt du skriver her, inkludert vedlegg og skjermbilder, kan leses av alle.
> Ikke del personopplysninger, som navn på elever, fødselsnummer, helseopplysninger eller skjermbilder som viser personopplysninger.
> Ikke del passord, tilgangslenker, tokens, API-nøkler eller annen informasjon som skal holdes intern.
> Ved opplasting av logger eller lignende, ta en nøye gjennomgang først.
 
## Slik bruker du repoet

- **Bruker:** Hvis du jobber i Statped så ta kontakt for å etablere en bruker kode. Utenforstående som melder inn skal bruke "Ekstern". Skjemaer uten "Ekstern" er ikke ment for eksterne tilbakemeldinger.
- **Feil eller problemer:** [Opprett en sak](https://github.com/llsynit/Feedback-intake/issues/new/choose) og velg riktig skjema.
- **Spørsmål eller ideer:** Bruk [Discussions](https://github.com/llsynit/Feedback-intake/discussions).

## Hva skjer etter at du har meldt fra?
 
Alle nye saker gjennomgås av en utvikler ved LLSYN i Statped, som vurderer og prioriterer dem. Du får varsel fra GitHub når saken din oppdateres.
